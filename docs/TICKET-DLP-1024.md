## 요약

관리자가 사용자의 파일 반출 요청을 조회하고 **승인 또는 반려**할 수 있는 기능을 개발합니다.

## 배경

현재 DLP 관리 콘솔에서는 파일 반출 **로그**만 사후에 조회할 수 있습니다. 하지만 고객사에서 **사전 승인 프로세스**에 대한 요구가 지속적으로 들어오고 있습니다. 반출 전에 승인을 거치도록 하여 보안 사고를 예방하고, 반출 이력에 대한 감사(Audit) 추적성을 확보해야 합니다.

## 상세 요구사항

### API 요구사항

- **RESTful API**로 구현
- 반출 승인 요청의 CRUD 기능
- **적절한 인증/인가 처리**
- 목록 조회 시 **페이지네이션** 지원
- **대용량 파일** 요청에 대한 고려
- 응답은 **일관된 JSON 포맷**

### 화면 요구사항

- jQuery 기반으로 구현
- **반출 요청 목록** 화면
  - 필터링: 상태(전체/대기/승인/반려), 날짜 범위, 요청자
  - 정렬: 최신순이 기본
- **요청 상세** 보기 (모달 또는 별도 화면)
- **승인/반려 액션**
  - 반려 시 사유 입력 필수
- 첨부된 시안을 참고하세요 → [`mockup-export-approval.svg`](./mockup-export-approval.svg)

### 데이터 요구사항

- 기존 `users`, `departments` 테이블 활용
- 반출 승인 요청 테이블 신규 생성 (Laravel 마이그레이션)
- **승인 이력을 관리**

### 비기능 요구사항

- **알림 기능 고려**
- 적절한 유효성 검증
- 에러 시 사용자 친화적인 메시지

---

## 인수 조건 (Acceptance Criteria)

- [ ] 사용자가 파일 반출 승인을 요청할 수 있다
- [ ] 목록에서 상태별 필터링이 동작한다
- [ ] 관리자가 요청을 승인하면 상태가 변경된다
- [ ] 관리자가 요청을 반려하면 사유와 함께 상태가 변경된다
- [ ] API 응답이 일관된 포맷이다
- [ ] `docker compose up`으로 실행 가능하다
